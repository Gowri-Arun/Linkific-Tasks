# Day 4: NumPy Fundamentals

Beginner-friendly NumPy practice with array basics and a student marks analysis.

## Requirements

- Python 3
- NumPy
- Jupyter Notebook (optional, for the notebook)

## Installation

```bash
pip install numpy jupyter
```

## Execution

Run the Python script:

```bash
python student_marks_analysis.py
```

Open the notebook:

```bash
jupyter notebook numpy_practice.ipynb
```

## Features

- 1D and 2D NumPy arrays
- Array properties, indexing, slicing, and axis operations
- Element-wise arithmetic and broadcasting
- Python list and NumPy array comparison
- Student totals, averages, highest and lowest marks, and top student
