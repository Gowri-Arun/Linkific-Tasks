# Student Record Management System

A beginner-friendly Python program for managing student records.

## Features

- Add students with an ID, name, age, and marks
- View all student records
- Search, update, and delete a student by ID
- Saves records in `students.txt` so they are available when the program starts again
- Checks basic invalid input and duplicate IDs

## Run

Open a terminal in this folder and run:

```bash
python main.py
```

Choose an option from the numbered menu and follow the prompts.
